# Project brief for Hoosier Goose Co.: "Somebody Did It First", Shorts batch 1

Updated 2026-10-09 by the Claude Code session building it. This goes alongside the main brief (`Somebody Did It First - Cowork brief.md`).

## What it is
- **Four Shorts, 45–60 seconds each,** voiced by Gus himself (a phone voice memo is fine).
- **Two jobs:**
  1. **Set the brand's sound.** They're the voice test that led to the podcast format, where Gus hosts in his own voice.
  2. **Promotion.** Once the podcast is live, Shorts and Reels clips are the main way new listeners find it (see `production/podcast/PODCAST-PLAN.md`).
- **Why Gus voices them.** It's the same workflow as Lumber Counter Talk and Heavier Runners. Gus records, Claude builds the visuals to his timing, and his recordings also surface fact problems and new ideas.

## Rules for every Short (from the channel memory file)
- **Voice.**
  - Plain talk; say each point once; assume the viewer knows basic history.
  - No "right?" and no asides.
  - Banned words: "genuinely", "dive in", "game changer", "unpack", "in today's video", "level up".
- **Facts.**
  - Every fact on the fact sheets has its source listed.
  - Keep each Short's hedge exactly as written.
  - Each sheet has a "stay away from" list: for example the Trevithick bet story, surgery detail, and Minoan "roof cisterns".
- **Fair credit.** The famous person gets their real due. Crapper "made toilets better"; the Stephensons built what lasted.
- **Visuals.**
  - Real photos, period prints, maps and the running time bar.
  - No AI "photos" of real people or events.
  - No cartoon reconstructions of historical machines; Gus rejected those twice.
  - On-screen text never says more than the narration.
- **Credits.** Every image is credited in the description.

## The workflow
1. **Gus records** all four, one take each, named 01–04, and sends them in the Claude Code chat.
2. **Claude builds each vertical (9:16) Short** to Gus's timing: real images, the time bar, burned-in captions, and the source credit. Then a check pass against the fact sheet.
3. **Gus approves and posts** to YouTube Shorts, Instagram Reels and TikTok, with sources in the description.
4. **What Gus's takes reveal** (pacing, phrasing he changed, facts that sounded off) gets written into the channel memory file and feeds the podcast prep sheets.

## Timing (proposal)

## Later batches
